# From forecasts to reserves

Reproducibility repository for **“From forecasts to reserves: Decision-focused evaluation of weekly dengue admissions in Bangladesh under potentially capacity-censored surveillance.”**

The study forecasts **reported hospital admissions**, not total dengue infections or latent admission-eligible demand. It then evaluates national-to-division reserve policies in admission-service-equivalent units. Claims about exact beds, staff, IV fluid, or unmet demand are intentionally outside the identifiable scope of the public data.

## Frozen study snapshot

- Reporting calendar: DGHS Sunday–Saturday weeks; week 1 contains 1 January. The encoded test maps 9–15 August 2026 to week 33.
- Primary forecast: equal-weight log-growth and histogram-gradient-boosting ensemble.
- One-week evaluation: 124 targets, MAE 226.5, WAPE 9.8%, and 85.6% empirical coverage for the nominal 80% interval.
- Biology-informed constraints did not reliably improve out-of-sample accuracy.
- Primary allocation evaluation: 101 comparable weeks. Point forecast plus pooled recent divisional shares produced 14.5% mean shortage, 11.1% admissions-weighted shortage, and 307.3 admission-equivalent shortfalls per week. Total allocated units were 96.8% of total observed admissions.
- Adaptive reserves improved unweighted shortage at matched aggregate budgets, but weighted and surge benefits were absent or uncertain.

These are retrospective expanding-window results. The selected ensemble requires prospective validation.

## Repository map

```text
data/raw/dghs/       cached aggregate DGHS dashboard responses
data/processed/      analysis-ready weekly dengue and weather inputs
manuscript/          LaTeX source, bibliography, figures, tables, and PDF
outputs/             machine-readable analysis outputs used by scripts
results/             compact set of principal results and reports
src/                 acquisition, harmonization, forecasting, and allocation code
work/                frozen intermediate inputs required by analysis scripts
MANIFEST.sha256      checksums for the packaged release
```

Large simulation-level latent-demand files are intentionally omitted because they are regenerated by `src/build_phase3_latent_demand.py`; their aggregate summaries are included.

## Fast offline reproduction

After Python and the packages in `requirements.txt` are installed, no internet connection is needed to regenerate the manuscript figures and generated tables from the frozen outputs:

```bash
python3 src/verify_repository.py
make assets
```

The regenerated files appear in `manuscript/figures/` and `manuscript/tables/`. To compile the article, install a LaTeX distribution with `latexmk`, then run `make paper`.

## Full analytical rebuild

Run `make full` to rebuild the forecast benchmark, spatial-policy audit, joint forecast-allocation evaluation, latent-demand sensitivity analysis, revision audit, and manuscript assets. Random seeds are fixed in the programs. See `REPRODUCIBILITY.md` for the execution order and expected inputs.

Data-acquisition programs are provided for auditability but are **not** run by `make full`. Refreshing source data requires internet access and may change the study snapshot. The programs use ordinary public requests and stop on failed responses; they do not bypass access controls.

## Data and missingness

Outcomes are never interpolated. A weekly target is used only when all constituent observations are complete or an exact, citable weekly total is available. Monthly counts are not divided into synthetic weeks, and the 2020–2021 weekly blackout remains missing. Weather variables are lagged point-location proxies from NASA POWER, not polygon-wide divisional averages.

See `DATA_AVAILABILITY.md`, `CODEBOOK.md`, and `results/reports/dengue_forecast_missing_value_protocol.md` before reuse.
